
# Marvellous Logic Building Assignment 4A

- Language: C
- Compiler: gcc (MinGW)
- IDE: VS Code

## Problems
1. Check whether a number is positive or negative
2. Check even or odd number
3. Find the greater of two numbers
4. Check voting eligibility
5. Check divisibility by 5

## Files
- program1.c to program5.c: C source files, one per problem

## How to run
gcc program1.c -o program1
./program1
